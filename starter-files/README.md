# Archivos iniciales (starter-files)

Cada carpeta contiene el código con el que **empieza** una lección (`index.html` y `style.css`). Los comentarios `PRÁCTICA` indican lo que debes hacer.

El archivo inicial de cada lección es el resultado de la lección anterior, así que tu página crece poco a poco. Para usarlo en CodePen, sigue los pasos de la sección «Cómo usar este repositorio» del [README principal](../README.md).

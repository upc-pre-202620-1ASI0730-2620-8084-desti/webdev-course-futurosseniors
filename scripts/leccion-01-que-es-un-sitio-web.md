# Guion - Lección 1: ¿Qué es un sitio web?

Duración aprox.: 6 minutos
Archivos: `starter-files/leccion-01-que-es-un-sitio-web` y `completed-examples/leccion-01-que-es-un-sitio-web`
Link del Pen: (pendiente)

## Objetivo

El estudiante entiende que una página web es un archivo de texto que el navegador convierte en lo que ve, y que HTML pone el contenido y CSS la apariencia.

## Escenas

### Escena 1: Portada y gancho (0:00 - 0:40) - Canva

Texto en pantalla: Lección 1: ¿Qué es un sitio web?

Lo que se dice: ¿Alguna vez te preguntaste cómo se hace una página como YouTube o la de tu colegio? Todas, absolutamente todas, empiezan con lo mismo que vas a aprender en este curso. Al final vas a tener tu propia página de perfil, y no vas a necesitar instalar nada: solo tu navegador.

### Escena 2: ¿Qué pasa cuando abres una página? (0:40 - 1:50) - Canva

Texto en pantalla: Tú pides > el servidor envía > el navegador dibuja

Lo que se dice: Cuando escribes una dirección en el navegador, tu computadora le pide la página a otra computadora llamada servidor. El servidor le envía archivos de texto con instrucciones. Tu navegador, que puede ser Chrome, Edge, Firefox o Safari, lee esas instrucciones y dibuja la página en tu pantalla. Es como pedir una receta: el servidor te manda la receta y el navegador cocina el plato.

### Escena 3: HTML y CSS (1:50 - 3:00) - Canva

Texto en pantalla: HTML = contenido (esqueleto), CSS = apariencia (ropa)

Lo que se dice: Esas instrucciones están escritas en dos lenguajes. HTML dice qué hay en la página: títulos, textos, fotos, enlaces. Es como el esqueleto. CSS dice cómo se ve: colores, tamaños, letras, bordes. Es como la ropa. Una página solo con HTML funciona, pero se ve simple. Con CSS se vuelve atractiva.

### Escena 4: Espiar una página real (3:00 - 3:50) - CodePen / navegador

Qué se hace: abrir cualquier página pública (por ejemplo, Wikipedia), clic derecho > Inspeccionar. Resaltar con una flecha una etiqueta `<h1>`.

Texto en pantalla: Clic derecho > Inspeccionar

Lo que se dice: Te comparto un truco: en cualquier página haz clic derecho y elige "Inspeccionar". Eso que ves es el HTML real de la página. No te asustes; en unos minutos vas a reconocer varias de estas palabras.

### Escena 5: Conociendo CodePen (3:50 - 4:50) - CodePen

Qué se hace: abrir el Pen de la lección 1. Señalar los paneles HTML, CSS y el resultado.

Texto en pantalla: Panel HTML, Panel CSS, Resultado

Lo que se dice: Para practicar vamos a usar CodePen, una página gratuita donde escribes código y ves el resultado al instante. A la izquierda va el HTML, al centro el CSS y abajo está la página que se va creando. Mira: aquí ya hay un título y un párrafo. Ahora, en el panel CSS, voy a borrar estos símbolos que "apagan" los estilos... ¡y listo! El fondo y el color del título cambiaron. Eso es CSS trabajando.

### Escena 6: Pausa para practicar (4:50 - 5:20)

Texto en pantalla: Pausa el video: cambia el texto del título y enciende el CSS

Lo que se dice: Te toca. Pausa el video, abre el enlace de la descripción, cambia el título por "¡Hola, soy..." y tu nombre, y enciende el CSS como yo. Cuando termines, dale play.

### Escena 7: Cierre (5:20 - 6:00) - Canva

Texto en pantalla: Resumen: navegador + HTML + CSS

Lo que se dice: Hoy aprendiste que el navegador lee archivos con instrucciones, que HTML pone el contenido y que CSS lo decora. En la siguiente lección vas a escribir tu primera estructura HTML desde cero.
